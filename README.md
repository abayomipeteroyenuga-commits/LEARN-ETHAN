# ETHAN LEARN v2.1 — Focused Core Subjects

Nigerian academic learning platform for Basic 1–5, JSS 1–3 and SS 1–3.

## v2.1 direction
- Removed Term 1 / Term 2 / Term 3 as the main learning navigation.
- Focuses on important subjects rather than attempting every curriculum subject shallowly.
- Basic 1–3: Mathematics, English Studies, Basic Science.
- Basic 4–5: Mathematics, English Studies, Basic Science & Technology, Basic Digital Literacy.
- JSS 1–3: Mathematics, English Studies, Intermediate Science, Digital Technologies, Business Studies.
- SS 1–3 core: General Mathematics, English Language, Digital Technologies.
- SS Science: Biology, Chemistry, Physics, Further Mathematics.
- SS Business: Economics, Financial Accounting, Commerce, Marketing.
- SS Humanities: Government, Literature in English, Nigerian History.
- Learning flow: Class → Priority Subject → Topic → Detailed Lesson → Practice → Assessment.
- Lesson shell follows Ethan LMS academic method: objectives, definitions, detailed explanation, worked examples, guided practice, independent practice, quiz, assignment, revision and examination-style questions.

This is the focused platform foundation. Full subject content should now be expanded topic-by-topic without changing this academic structure.

## v2.2 Mathematics Full-Content Expansion
- Mathematics now has class-specific, age-progressive lesson content from Basic 1 through SS3.
- Each mathematics lesson contains learning objectives, introduction, detailed concept sections, worked examples, practice, quiz, assignment and revision/examination practice.
- The mathematics topic list is no longer the same generic bank for every class.


## v2.3 English Full Content
- Detailed English Studies/English Language lessons for Basic 1–5, JSS 1–3 and SS 1–3.
- Objectives, explanations, examples/application, guided and independent practice, quizzes, assignments and revision/examination practice.
- Mathematics v2.2 content remains intact.
